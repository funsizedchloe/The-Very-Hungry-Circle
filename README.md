# Spring26-IMED-120
This is my IMED 120 Final Project 

Players will use the arrow keys to move their circular avatar around the screen.
The goal of the game is to collect as many square food items as possible within a 1 minute countdown.
There will also be triangle spikes on the map that will hurt the player causing them to loose a life.
If the player loses 5 lives before the timer runs out the game is over.
